# FarmMitra AI

Farmer-first crop photo guidance and mandi price alerts app.

## Complete source

The full Replit workspace source is included in **farmmitra-ai-source.tar.gz**. It excludes only installed dependencies, local caches, build output, and private workspace metadata.

## Run

Extract the archive, install with pnpm, then run the FarmMitra AI web package with the configured PORT and BASE_PATH environment variables.

## Product

- Crop photo upload and first-look analysis flow
- Hindi / English guidance
- Crop and mandi watchlist
- Mandi trend cards and alert subscription
- NGO / B2B partnership interest flow
